# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and integrity of mobile playback systems seriously. If you discover a security vulnerability or exploit (such as buffer overflow risks in decoding pipelines, sandbox leaks, or insecure storage of cached segments), please report it responsibly.

### How to Report
- **Do not open a public issue.**
- Report security concerns via GitHub Private Vulnerability Reporting on this repository.
- Include detailed reproduction steps, target Android/iOS versions, and proof-of-concept manifests if applicable.

### Response Timeline
- An acknowledgment will be sent within 48 hours.
- A fix or mitigation will be prioritized and published in a security patch release.
